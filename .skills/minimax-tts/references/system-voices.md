# 本技能指定音色名单

仅支持下列 38 个音色。这是本技能主动限定的产品范围，不是厂商全部音色。普通话8个、粤语1个（中文共9个），英文8个，其他语种各1个。依据官方名称做场景覆盖筛选，未逐一试听或实测。
来源：https://platform.minimaxi.com/docs/faq/system-voice-id（2026-09-17核对）。
UI和服务端只读取 assets/system-voices.json，禁止扩展名单、根据名称猜ID或加入自定义音色。
