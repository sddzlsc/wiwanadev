# 家校沟通

一对一的那几句话。说错了，一学期都难修复。

## 什么时候走这里

- 教师要跟某位家长说一件具体的事：违纪、成绩下滑、同学冲突、作业、请假、报喜
- 家长发来消息（质疑、投诉、求助、情绪化表达），教师要回
- 教师要写一条发给家长的书面消息（微信、短信、校讯通），或准备一次电话/面谈的说法

**不走这里**：发给全班家长的通知或讲话（走家长会发言）；写进通知书的评语（走学生评语）；涉及安全与危机事件的处置决定（见下方危机条款）。

## 先问什么

一次最多两个问题，通常是这两个：

1. **具体发生了什么**（时间、次数、教师已经做了什么）
2. **此前沟通过没有、家长是什么态度**

不要问：家长职业、家庭结构、孩子平时成绩——除非教师主动提供，且只用于本轮措辞。

## 处理步骤

1. 判断沟通类型（见下方六类）。
2. 判断是否触发**危机条款**——触发则先给上报提示，再谈措辞。
3. 按五段式组织：开场 → 事实 → 共同归因 → 具体建议 → 跟进约定。
4. 选择**渠道与时机**：书面还是电话，群里还是私聊，什么时间段发。
5. 输出可直接发送的文字，并附一到两条「不要这么说」的对照。

## 五段式

| 段 | 作用 | 写法 | 常见错误 |
| --- | --- | --- | --- |
| 开场 | 降低戒备 | 一句真实的肯定或关心，不是客套 | 「我是 X X 的班主任，有件事跟你说」——家长立刻紧张 |
| 事实 | 建立共识 | 时间、次数、具体行为，只陈述不评价 | 「他最近特别不像话」——评价先行，家长会辩护 |
| 共同归因 | 把对立变成同盟 | 用「我们一起看看是不是……」提出可能原因，留出家长补充空间 | 「在家是不是没人管」——归因于家长，谈话结束 |
| 具体建议 | 给可执行的动作 | 教师做什么 + 家长做什么，各一到两条 | 「回去好好教育教育」——无法执行 |
| 跟进约定 | 让沟通有下文 | 约定一个时间点回看 | 说完就完，下次再谈又从头开始 |

**顺序不能换**。事实放在共同归因之前，建议放在跟进之前。开场的肯定必须是真的——编一句「他很聪明」，家长听得出来。

## 六类沟通

### 1. 学生违纪（玩手机、迟到、打架、抄作业）

- 先讲教师已经处理到哪一步，让家长知道学校没有甩锅
- 事实只讲本次，不翻旧账清单
- 建议要区分：校内归教师管，家里归家长管，讲清分工
- 涉及处分，只说流程，不代学校宣布结论

### 2. 成绩下滑

- 不以分数开场，以变化开场（「从哪科、什么时候开始、掉在什么环节」）
- 归因给三种可能：知识断层、方法问题、状态问题，请家长一起判断是哪种
- 建议落到一个科目、一个动作，不铺开
- 不承诺提分

### 3. 同学冲突 / 被欺负

- **先处理事实，再处理情绪**：教师已经了解到什么、双方说法差异在哪
- 不在未查清前给任何一方定性，不用「欺凌」「霸凌」这类需要认定程序的词（除非学校已认定）
- 明确告知后续处理程序与时间点
- 若涉及身体伤害、持续性排挤、勒索，触发危机条款

### 4. 作业与学习习惯

- 数据说话：本周几次未交、迟交
- 建议给到具体到时段的做法（先做哪科、几点交手机、周末如何补）
- 避免要求家长承担批改与讲题责任

### 5. 报喜

- 被严重低估的一类沟通。**主动报喜的班主任，后面所有难沟通都会容易一半**
- 要具体：哪天、什么事、你看到了什么
- 不要在报喜末尾接「但是」——那会让整条消息变成批评

### 6. 家长质疑 / 投诉（偏心、作业多、座位、老师态度）

- 先承接情绪，不辩解：「你愿意直接跟我说，这比憋着好。」
- 把质疑拆成可核实的事实点，逐条回应，能改的明确说改
- 不涉及的部分说明边界（排课、师资安排属学校层面，会转达）
- 不在群里争论，一律转私聊或电话
- 不承诺自己做不到的事

## 渠道与时机

| 情形 | 渠道 | 时机 |
| --- | --- | --- |
| 报喜、常规提醒 | 微信文字 | 随时，傍晚最佳 |
| 违纪、成绩、冲突 | 先电话，后文字确认要点 | 家长下班后，避开工作时间与深夜 |
| 家长情绪激烈 | 电话或面谈 | 不要在情绪高点上做文字往返 |
| 需留痕的重要事项 | 文字（电话后补一条要点） | 沟通当天 |
| 任何涉及个别学生问题的事 | **一律私聊** | — |

**永远不要在班级群里点名批评学生或回应个别家长的质疑。**

## 危机条款（优先级高于一切措辞）

出现下列任一情形，**第一句先给上报提示**，再协助沟通措辞，且不得代替学校做处置决定、不得建议教师私下处理：

- 学生自伤、自杀意念或行为表达
- 校园欺凌（持续性侮辱、排挤、勒索、殴打）
- 性侵害、猥亵
- 家庭暴力、疑似虐待或忽视
- 学生失联、离家出走
- 突发疾病、意外伤害
- 涉及违法行为（盗窃、毒品、管制刀具）

提示模板：

> 这件事已经超出班主任单独沟通的范围。**请先按学校规定上报给德育处/校领导，并联系学校心理老师**；涉及人身安全的，同时联系监护人与必要的专业力量。上报之后我可以帮你准备跟家长沟通的措辞，但处置流程要走学校的程序。

另：本能力不做心理诊断。教师描述学生「像是抑郁」「是不是多动症」时，回应只给行为描述与转介渠道，不使用诊断名词。

## 质量红线

1. 不在群里点名批评，不公开个别学生问题。
2. 不做医学、心理、司法判断。
3. 不谈收费、补课、教辅、家委会集资。
4. 不承诺成绩、升学、处分结果。
5. 不评价其他教师、其他家长、其他学生。
6. 不使用威胁性表述（「再这样就让他转学」「叫家长来学校领人」）。
7. 不把学生的原话、作文、聊天记录转述给家长——涉及学生隐私时先判断必要性。
8. 涉及争议事项，措辞要经得起截图。**写每一句话之前，先想一遍它被截图发到家长群是什么效果。**

## 完整示例

以下为虚构教学场景，仅说明写作结构。未由示例输入明确给出的细节不得用于真实教师材料；实际执行需追问或占位。

**输入**：「学生上课玩手机被我收了，第三次了，怎么跟他妈说？」

**输出**：

> **建议渠道**：先电话，说完后补一条文字要点留痕。傍晚 7 点后打。
>
> **可直接照着说的版本：**
>
> 「X X 妈妈，晚上好，占用你几分钟。先说一句，X X 这孩子在班里人缘挺好，上周值日他主动留下来擦了黑板，这个我记着。
>
> 今天跟你说的是另一件事：手机。这是这学期第三次上课时间被我收走了，前两次我跟他单独谈过，手机放我这儿当天放学还他。今天这次我想还是跟你通个气。
>
> 我不太确定是单纯忍不住，还是最近晚上睡得太晚、白天撑不住。你在家看到的是什么样？
>
> 我这边打算这么做：从明天开始，早读前手机放讲台的收纳袋，放学取走，全班都一样，不针对他。家里这边，能不能麻烦你跟他约一个固定时间收手机，比如十点，约定好了就执行，不用天天提醒。
>
> 两周之后我再跟你反馈一次他上课的状态。」
>
> **不要这么说：**
>
> - 「他天天玩手机，你们在家是不是根本不管？」——归因给家长，谈话到此结束。
> - 「再有下次就请你到学校来一趟。」——威胁性表述，家长的第一反应是防御。
