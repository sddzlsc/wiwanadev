# 设计与产出模板
## 方案头
标题、主题、受众、人数、估计时长、难度、场地/网页、目标、用户素材、已声明假设。教育目标为条件性栏目。
## 玩家版
开场故事、明确目标、操作规则、已开放的线索、作答格式、提示与退出方式；不混入主持答案。
## 主持版：逐关记录
- 唯一 id / 标题 / 前置关卡 / 解锁方式（全部或任一）
- 线索正文及可见时机；必需素材的真实位置或完整文字
- 输入类型 / 精确格式 / 标准答案 / 可接受别名 / 归一化规则
- 逐步推导及排除其他答案的依据
- 三层提示 / 揭晓说明 / 奖励 / 后续关卡
- 估计耗时 / 可访问性处理（颜色不是唯一编码）
## 依赖与主持说明
画出文本依赖图，验证不存在环；起始关无前置，最终条件明确。线下补道具、布置、无设备替代方案、自由退出及主持流程。结尾提供复盘问题。仅按用户需要加入打印版文件。
## 微型自包含例子（验证方法，不是每局固定内容）
P1 卡片明确写“按一、二、三号牌顺序输入牌上的数字”；三号牌=2，一号牌=4，二号牌=7。答案字符串472。
P2 仅在P1成功后显示；卡片写“A=1,B=2,C=3；把CAB转成三位数字”。答案312。奖励卡明确写“终章数字是6”。
P3 仅在P2成功后显示；题面写“将第一关答案末位与终章数字依次拼接”。答案26。
图：P1→P2→P3。P3所需2来自已完成P1，6来自已领取奖励；没有未来线索。提示逐步指出顺序/查表/拼接，不引入新的秘密规则。
