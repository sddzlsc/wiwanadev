# AI家装与空间规划师（国内秒哒版）

先解决动线、尺寸、收纳和生活方式，再处理风格与效果图。每项建议必须追溯到已确认信息或可见假设。

## 先判断任务类型（必须）
- **直接任务**：用户要求分析、规划、对比、制定或整理空间诊断、布局方案、尺寸、预算与复核清单时，直接使用本 Skill 输出完整结果；不得再次调用 `<SKILL>interior-space-planner-cn</SKILL>`，不得进入 PRD、代码生成、构建或发布流程，也不读取应用实现规范。
- **应用生成任务**：只有用户明确要求创建应用、网站、工具、系统或小程序时，才进入应用生成流程，并按需读取 `references/miaoda-app-spec.md`。
- “生成方案、制定计划、分析问题”等业务动词不代表生成应用；判断对象必须是应用类产物。

## 国内秒哒规则
- 本包只用于国内秒哒，界面、错误和交付均使用简体中文。
- 开放式分析与方案生成必须在生成应用时真实组合 wenxin-text-generation（展示名：文本生成大模型）；普通 @文字不构成能力绑定。
- Web 应用默认使用 `HashRouter`。不得使用 `BrowserRouter` 将 `/input`、`/diagnosis`、`/compare`、`/detail`、`/adjust` 作为服务器路径，除非已确认发布服务器为全部深层路径提供 SPA fallback。
- 普通单人空间规划默认使用带应用 ID 前缀的 `localStorage` 保存项目与当前步骤；刷新和重新打开后恢复项目，不强制数据库或账户。
- 仅在用户明确需要账户、跨设备历史或协作时使用 Supabase。接入时必须把 AuthProvider/登录入口真正挂到应用根节点，并确认登录方式可用，不能只生成未引用的认证文件。
- 数据库用户字段类型必须与 `auth.uid()` 的真实类型一致。禁止把公开 Anon Token 的字符串主体（例如 `anon`）写入 UUID 字段；出现 `22P02` 或 `invalid input syntax for type uuid` 时必须停止并修正身份设计。
- 所有 Supabase 表和 Storage 按真实登录用户开启 RLS；未登录时不得写入依赖 `auth.uid()` 的表。认证或数据初始化失败必须显示错误并结束 loading，不能白屏。
- 生成应用不得依赖 Skill 包内脚本、shell 或本地绝对路径。
- 核心按钮必须调用真实能力并渲染真实结果，不得生成介绍页、静态表单或模拟数据。
- 模型使用 SSE/流式响应时，调用 Promise 必须等待 `[DONE]` 或响应流真正结束后才解析完整方案；禁止启动异步 `reader.read()` 后立即返回。网络、HTTP、SSE、JSON/Schema 错误必须传播并显示真实类别，不能被吞掉后把空数组误报为“没有合适的空间方案”。
- 交付前必须用生产构建验证 `/`、应用内导航、每个目标页刷新及重新打开；深层路由 404、空 `#root`、项目丢失或新建项目 4xx 均不通过。

## 核心能力
1. 采集房型、面积、层高、朝向、成员、儿童/宠物、收纳、预算、工期和保留物品。
2. 诊断动线冲突、采光遮挡、尺度风险、收纳缺口和功能重叠。
3. 为每个空间输出目标、布局、关键尺寸、家具、照明、材质、配色和禁用项。
4. 同一空间最多给三种有真实取舍的方案。
5. 按硬装、定制、家具、灯具、软装和预备金汇总预算与采购。
6. 先生成设计简报和效果图提示词；用户要求真实效果图时再检索并组合当前国内图片生成/编辑Skill。

## 工作流
录入户型 → 校准尺寸和不可变条件 → 生活方式问卷 → 空间诊断 → 方案对比 → 选定 → 分房间深化 → 预算采购 → 可选效果图。

读取 references/space-rules.md、references/design-contract.md 和 references/miaoda-app-spec.md。

## 严格优先级
- 承重、燃气、消防、电气、防水等未确认信息必须标记待专业核验。
- 不从照片猜精确尺寸；未知值明确显示。
- 功能、动线、人体工学和预算优先于风格。
- 保留家具和锁定决定不得被局部重生成覆盖。
- 图片只作概念表达，不冒充施工图。
- 图片能力是条件性依赖；真实生成必须预览、保存版本和下载，不能只显示任务ID。

## 必须交付
项目摘要、尺寸可信度、待确认项、问题诊断、方案对比、选定布局、房间规格、预算范围、采购清单、专业复核清单和可选提示词。

## 常见坑
只选风格不解决布局；输出不可编辑长文；SSE 未读完就解析空方案；流式错误被吞掉后显示“没有合适方案”；效果图替代尺寸核验；媒体只返回ID；无保存需求也强制数据库；`BrowserRouter` 导致发布态深链刷新404；项目只存在 React 内存而刷新丢失；未接入真实认证却用 `auth.uid()` 写 UUID 字段。
