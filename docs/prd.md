# 需求文档

## 1. 应用概述

### 1.1 应用名称
北京万维速达科技有限公司企业官方网站

### 1.2 应用描述
构建一套现代科技风格的企业官方网站，展示公司核心优势、服务承诺与五大核心业务矩阵，提供多触点快捷联系方式及在线需求留资表单，满足全国远程交付与本地软件开发业务拓展需求，同时符合主流搜索引擎收录规范。

## 2. 用户与使用场景

### 2.1 目标用户
- 有软件开发、微信小程序定制、企业官网建设、移动App开发或AI/大模型技术落地需求的企业及个人客户。

### 2.2 核心使用场景
- 客户访问官网了解万维速达的技术实力、业务范围及交付承诺，通过留资表单提交项目需求或通过一键拨号/微信直接联系负责人。

## 3. 页面结构与功能说明

### 3.1 页面结构

```
企业官网
├── 首页
│   ├── 首屏视觉与核心卖点区
│   ├── 零风险承诺与信任背书区
│   ├── 核心业务矩阵区
│   └── 在线需求留资区
├── 全局悬浮联系挂件
└── 全局页尾
```

### 3.2 功能说明

#### 3.2.1 首页 - 首屏视觉与核心卖点区
- 展示公司品牌名称「北京万维速达科技有限公司」及科技感视觉背景。
- 核心提炼展示三大核心卖点：支持全国远程交付、最快1小时源码交付、高性价比。
- 包含引导行动按钮，点击可快速锚点定位至在线留资表单或唤起联系通道。

#### 3.2.2 首页 - 零风险承诺与信任背书区
- 醒目包装并展示零风险服务承诺：「1天内免费出Demo，满意再付定金，不满意零费用」。
- 展示全国交付与本地服务保障说明，强化客户信任感。

#### 3.2.3 首页 - 核心业务矩阵区
系统化展示五大核心业务模块，各模块包含服务介绍及落地场景：
- 微信小程序定制：展示定制开发范围与典型适用场景。
- 企业官网建设：展示品牌建站、营销型网站解决方案与场景。
- 原生/跨平台APP开发：展示iOS与Android双端开发服务与场景。
- AI智能体搭建：展示业务智能体、自动化工作流等落地场景。
- 大模型本地私有化部署：展示大模型本地算力适配与私有化部署服务场景。

#### 3.2.4 首页 - 在线需求留资区
- 精简型需求表单，包含输入项：联系人姓名、联系电话/微信、项目需求简述。
- 提交按钮：用户提交后后端存储留资数据并提示提交成功。

#### 3.2.5 全局悬浮联系挂件
- 常驻页面侧边，展示负责人信息：负责人「李守聪」、电话/微信「18315852058」。
- 电话快捷操作：移动端支持一键拨号。
- 微信快捷操作：点击触发微信二维码弹窗，支持扫码或复制微信号。

#### 3.2.6 全局页尾
- 展示公司全称、负责人姓名及联系方式（18315852058）。
- 汇总展示核心业务导航链接及版权信息。

#### 3.2.7 搜索引擎友好规范（TDK与语义化）
- 页面标题（Title）、描述（Description）、关键词（Keywords）配置包含核心关键词：「北京软件开发」、「北京小程序外包」、「北京大模型私有化部署」。
- 页面采用标准语义化标签结构组织内容层级。

## 4. 业务规则与核心逻辑

### 4.1 留资校验规则
- 联系人姓名与联系电话为必填项。
- 联系电话需符合标准手机号格式校验规则，未填或格式不正确时提示错误。
- 提交成功后清空表单输入内容并显示成功提示信息。

### 4.2 数据存储规则
- 用户提交的留资信息需持久化存储至后端数据表，记录提交时间、姓名、联系方式与需求描述。

## 5. 异常与边界情况

| 场景 | 表现与处理 |
| :--- | :--- |
| 用户提交空白表单 | 提示「请输入联系人姓名及联系电话」并阻止提交 |
| 手机号码格式错误 | 提示「请输入正确的手机号码」并保持已输入内容 |
| 表单重复快速点击提交 | 提交中状态禁用提交按钮，防止重复提交 |

3. 全站悬浮挂件与页尾正确显示负责人李守聪及电话/微信18315852058，移动端点击支持一键拨号，点击微信可弹出二维码。
4. 在线留资表单支持输入姓名、联系电话、需求并成功提交，表单校验规则正常生效且数据存储成功。
